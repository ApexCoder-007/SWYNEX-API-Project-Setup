**## Installation**



**1. Clone this repository.**

**2. Create virtual environment:**



&#x20;  **python -m venv venv**



**3. Activate it:**



&#x20;  **.\\venv\\Scripts\\Activate.ps1**



**4. Install dependencies:**



&#x20;  **pip install -r requirements.txt**



**5. Run:**



&#x20;  **python app.py**



**6. Open http://127.0.0.1:5000/**
